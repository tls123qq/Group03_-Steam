05_AI_Usage_Log/
=================
โฟลเดอร์นี้ใช้เก็บ AI Usage Log ตามข้อกำหนดของงาน

ต้องมีอย่างน้อย 5 prompt สำคัญ โดยแต่ละรายการระบุ:
  1. Prompt ที่ใช้
  2. สิ่งที่ AI แนะนำ
  3. สิ่งที่กลุ่มนำไปใช้จริง หรือแก้ไขจากคำแนะนำนั้น
  4. วิธีตรวจสอบว่าผลลัพธ์ถูกต้อง

ตัวอย่างวิธีตรวจสอบที่ใช้ได้จริงในโปรเจกต์นี้:
  - รันสคริปต์กับข้อมูลจริงแล้วเทียบจำนวนแถวก่อน/หลังทุกขั้น (02_ETL/reports/)
  - รัน python 02_ETL/04_validate_dw.py ตรวจ PK/FK/Grain/Business Rules 95 รายการ
  - รัน python -m pytest -q ตรวจตรรกะการ clean ทีละฟังก์ชัน
  - เทียบผลรวม measure ผ่าน bridge table ทั้งแบบคูณและไม่คูณ allocation_factor
